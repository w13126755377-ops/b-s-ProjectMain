# 企业审批系统 使用手册

> 适用版本：1.0.0 ｜ 配套文档：[设计文档](设计文档.md) ｜ 演示视频见提交材料

## 1. 系统简介与访问

企业审批系统是一套 B/S 架构的多角色审批平台，支持采购、差旅、报销三类内置流程与管理员自定义流程模板，覆盖申请、审批、通知、统计全链路，手机与桌面浏览器均可使用。

**部署与访问**（详见 README.md）：

```bash
docker compose up -d --build
# 浏览器访问 http://localhost:8080
```

## 2. 注册与登录

1. 首页登录框输入**用户名或邮箱** + 密码（密码规则：8~64 位，须同时包含字母与数字，建议含大小写与符号）。
2. 无账号时点击「立即注册」：填写用户名（3-20 位字母/数字/下划线）、姓名、邮箱、密码、申请加入的部门。
3. **注册后部门归属需管理员确认**：在确认前可以登录、填写草稿，但不能提交申请（见 §11.1）。
4. 退出登录：右上角头像菜单 → 退出登录。

## 3. 工作台

登录后进入工作台，包含：

- **问候与待办提醒**：当前待办数、已办数、申请状态分布（草稿/审批中/已通过/已驳回/已撤回）。
- **快捷入口**：发起申请、我的申请、审批任务、通知中心。
- **近 6 个月提交趋势图**（口径：按提交时间；草稿不计入）。
- **部门/企业统计**（仅对部门负责人、财务、企业负责人、管理员显示；财务与企业负责人需管理员在「统计授权」中授予，见 §11.7）。

## 4. 发起申请

「发起申请」→ 选择流程模板：

- **采购申请 / 差旅申请 / 报销申请**：三类内置流程。
- **自定义流程**（如演示的「请假申请」「用章申请」）：仅显示**适用于本人部门**的已启用模板。

### 4.1 采购申请

1. 填写采购原因、项目、期望到货日期、预算上限（元）。
2. **采购明细**：至少 2 条（名称/规格/数量/单位/预计单价），小计自动计算。
3. **报价单**：至少 1 家供应商（名称/报价日期/报价金额/报价明细）。规则：
   - 必须且只能勾选 **1 家「拟选」**供应商；
   - 只有 1 家报价 = **单一来源采购**：必须填写单一来源说明；
   - 拟选供应商**不是最低价**时：系统提示并必须填写选择理由；
   - 勾选「线上采购」：必须填写购买链接并上传截图等报价依据（JPEG/PNG/PDF）。
4. 金额以"元"录入，系统统一换算为**分**存储与计算。

### 4.2 差旅申请

填写目的地、出发地、起止时间（结束不得早于开始）、出差目的、交通方式、同行人员、费用预算。
**出差天数由系统计算**（口径：按起止时间差折算，不足一天按一天计，向下取整小时差 → 向上取整天），申请人不可自行填写。

### 4.3 报销申请

1. 填写报销说明；可选**关联申请**：仅能关联**本人已批准**的差旅或采购申请（下拉框中仅列出符合条件的单子）。
2. **费用明细**：至少 3 条；费用类型 5 类（交通/住宿/餐饮/办公/其他）；每条填写发生日期、用途、金额。
3. **票据规则**：
   - 每条明细默认至少关联 **1 份票据**（JPEG/PNG/PDF，单文件 ≤10MB）；
   - 确无票据时勾选「无票」，**必须填写原因**——财务审核界面会突出显示无票支出；
   - 同一张报销单内，同一票据文件、同一票据号码不可重复使用；
   - 票据号码或文件内容（MD5）出现在**其他报销单**中时，提交与详情页会给出**跨单重复票据预警**（警告不阻断，供财务审核重点核查）。
4. 合计金额由**服务端重新计算**（各明细金额之和），客户端输入的合计无效。

### 4.4 自定义流程

按模板设计动态生成表单：文本/长文本/数字/金额/日期/单选/附件字段，支持必填、数值范围校验与**条件显隐**（如请假类型选「病假」才显示"病假证明"上传）。金额字段按元录入、按分存储。

### 4.5 保存草稿与提交

- **保存草稿**：随时保存；保存后才可上传附件（附件归属于申请单）。草稿可反复编辑、删除。
- **提交**：提交后进入审批流程，**不可再修改**；提交时系统生成完整审批链快照（此后管理员修改模板不影响本单）。
- 提交成功后进入申请详情页，可查看审批进度并收到后续通知。

## 5. 我的申请

列表支持按**类型 / 状态 / 时间范围 / 关键词（标题或编号）**筛选 + 分页；显示申请编号（如 `CG20261110-0001`）、金额、当前审批人、状态。

| 状态 | 可执行操作 |
| --- | --- |
| 草稿 | 编辑、提交、删除 |
| 审批中 | 撤回、催办（每个节点限 1 次） |
| 已驳回 / 已撤回 | 复制重提（生成新编号的草稿，附件共享物理文件） |
| 已通过 | 查看详情 |

## 6. 申请详情与审批

详情页包含：

1. **基本信息**：编号、标题、类型、金额、申请人、提交时间、模板版本、来源单（复制重提时显示）。
2. **审批进度**：节点链（每节点的审批人；委托代办会标注"受托代办：原审批人"）+ 审批时间线（提交/通过/驳回/撤回的完整记录与意见）。
3. **业务信息**：按类型展示明细、报价、票据；报销单突出显示**无票支出原因**与**重复票据预警**；可预览/下载附件（图片在线预览、PDF 新窗口打开）。
4. **操作**：
   - 当前节点审批人：**批准**（意见可选）/ **驳回**（理由必填）；
   - 申请人：撤回 / 催办 / 复制重提（视状态）。

**并发与幂等**：撤回与审批同时发生时只有一方成功；双击/多窗口重复操作会提示"状态已变化"（409），以最终状态为准。任何人**不能审批自己的申请**。

## 7. 审批任务

「审批任务」分两个页签：

- **待办**：当前节点是自己的申请（委托代办会带"代"标签）；可直接批准/驳回。
- **已办**：自己处理过的申请与当时的意见。

## 8. 通知中心

- 新待办、申请通过/驳回/撤回、催办都会生成**站内通知**，右上角铃铛显示未读数。
- 通知**实时推送**（SSE），页面打开即最新；浏览器不支持或断线时自动降级为 30 秒轮询。
- 点击通知跳转到对应申请详情；支持单条已读、全部已读；同一业务事件不会重复通知（幂等去重）。
- **超时催办**：审批节点超过配置时长（默认 48 小时，可调）未处理，系统自动向审批人发送催办通知（每个超时窗口一次）。

## 9. 个人中心

- 查看/修改姓名、邮箱（邮箱唯一）；查看部门与**部门归属确认状态**。
- 修改密码：需验证旧密码，新密码 ≥8 位且须包含字母与数字，修改后重新登录。

## 10. 审批委托

出差/休假前可设置委托：选择受托人、生效时间段、原因。

- **生效口径**：委托在**提交时解析**——委托生效期间新提交的申请，相关节点转交受托人办理，审批记录中标注原审批人与受托人。
- **安全约束**：部门负责人/财务/企业负责人节点的受托人**必须持有对应角色**（部门负责人还须同部门），防止高权限审批权外流。
- 委托可随时停用/删除；同一时间段仅一条生效委托。

## 11. 管理后台（admin 账号）

### 11.1 用户管理
列表检索（关键词/部门/角色）；编辑姓名、启停账号（停用后无法登录）、调整部门；**确认部门归属**（新注册用户默认未确认，未确认不能提交申请）；**授予/收回角色**（普通员工/部门负责人/财务/企业负责人/管理员）。所有变更写入审计日志。

### 11.2 部门管理
部门增改删（部门下有用户时禁止删除）；注册时可选部门。

### 11.3 流程模板
- 查看全部模板（内置 3 类 + 自定义），含版本与启用状态。
- **新建自定义模板**：名称、描述、适用部门（不选=全部部门）、表单字段设计（7 种字段类型、必填、数值范围、条件显隐）、审批节点设计（≥2 个节点，可排序；审批人规则：部门负责人 / 财务 / 企业负责人 / 指定用户）。
- **发布**：发布前自动校验（字段标识唯一、条件引用有效且无循环、节点完整、审批人规则有效、指定用户存在且启用）；发布即启用新版本，**同编码旧版本自动停用**。
- 编辑已发布/已停用模板会**自动生成新版本草稿**；**已提交的申请不受模板后续修改影响**（提交时快照隔离）。
- 内置模板不可修改/停用。

### 11.4 系统配置
- **企业负责人加签阈值**（默认 ¥100,000）：申请金额 ≥ 阈值时自动在审批链末尾追加"企业负责人审批"节点。
- 票据数量上限、票据总大小上限、单文件上限（单文件 ≤10MB 为作业要求，可调小）。
- **催办超时小时数**：审批超时自动催办（演示可调成 0.02 即约 1 分钟）。
- 配置修改全部留审计。

### 11.5 审计日志
管理员操作全留痕（停用用户、确认部门、授予角色、发布模板、修改配置、统计授权等），含操作人、对象、前后值。

### 11.6 数据统计
管理员可见全部部门全部类型：类型×状态分布、按部门已通过金额、近 6 个月已通过金额趋势。
**口径**：按提交时间统计；已通过金额仅含"已通过"申请；草稿/驳回/撤回不计入。

### 11.7 统计授权
财务（报销+采购全部门统计）、企业负责人（全部部门全部类型统计）需在此**明确授权**后才能在统计页看到企业数据；部门负责人按角色自带本部门统计；管理员自带全部权限。

## 12. 移动端使用

手机浏览器直接访问即可，全部核心操作（发起、审批、通知、查看进度）均已适配；页面打开时自动同步最新数据（实时推送/轮询兜底）。演示建议使用浏览器开发者工具切换手机视口。

## 13. 常见问题

| 现象 | 说明 |
| --- | --- |
| 提交时报"部门归属尚未经管理员确认" | 新注册用户需管理员在用户管理中确认部门（§11.1） |
| 提交时报"节点审批人为申请人本人" | 不可自审批；请设置审批委托或联系管理员调整流程/角色 |
| 拟选供应商不是最低价无法提交 | 必须填写选择理由（采购规则） |
| 报销明细无法提交 | 检查：明细≥3 条；每条须有票据或无票原因；同单内票据文件/号码不可重复 |
| 提示"该申请状态已变化" | 他人已处理/已撤回，刷新查看最新状态 |
| 催办提示"该节点已催办过" | 每个节点手动催办限 1 次，超时会自动催办 |
| 财务/企业负责人看不到企业统计 | 需管理员在「统计授权」中授予（§11.7） |
| 浏览器没收到推送提醒 | Web Push 需 HTTPS 且服务器配置 VAPID；站内通知与 SSE 不依赖此配置 |
